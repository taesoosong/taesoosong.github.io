# Taesoo Song — academic website

Personal academic website for Taesoo Song, Assistant Professor of Urban and
Environmental Policy and Planning at Virginia Tech.

The site is built with Jekyll and published through GitHub Pages.

## Local development

\`\`\`sh
bundle install
bundle exec jekyll serve
\`\`\`

Publication records live in \`_data/publications.yml\`; homepage updates live in
\`_data/news.yml\`, and featured work lives in \`_data/recent_work.yml\`.
